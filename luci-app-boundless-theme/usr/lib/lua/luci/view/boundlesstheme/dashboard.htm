Ganti Tema

Pilih tema terdaftar lalu klik Aktifkan — sama seperti dropdown Design di System → Language and Style, tanpa pindah halaman. LuCI restart sebentar setelah tema diganti.

Install / Update

Tema dipasang & diperbarui dari repo GitHub boundless-luci (rilis terbaru). Klik Cek Update untuk membandingkan versi.


  


  

    
Rollback & Hapus

    
Rollback: aktifkan lagi tema yang dipakai sebelum Boundless (file tema tetap ada). Hapus Tema: rollback + hapus semua file Boundless dari perangkat. Selama proses, LuCI akan restart — halaman ini ikut terputus sebentar, itu normal.
